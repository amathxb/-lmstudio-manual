Sección 01

¿Qué es LM Studio?

ChatGPT dentro de tu laptop — sin internet, sin facturas, sin que nadie vea tus consultas.

Con LM Studio el proceso entero ocurre localmente: el modelo carga en tu RAM/VRAM, hace los cálculos y responde sin salir de tu máquina. LM Studio actúa como interfaz gráfica sobre llama.cpp, la biblioteca de bajo nivel que soporta NVIDIA CUDA, AMD ROCm, Apple Metal y CPU pura.

Flujo de inferencia

Tú → LM Studio → llama.cpp → Modelo → Respuesta

Cuantización (Q4, Q5, Q8)

Un modelo en precisión completa puede pesar 30–130 GB. La cuantización lo comprime a menos bits — como pasar de foto RAW a JPEG de alta calidad: el ojo apenas nota la diferencia.

✅ Q4_K_M — Estándar Recomendado

4 bits · ~4.8 GB (8B) · Calidad muy buena · Rápida. El punto óptimo. Para GPU 8–12 GB VRAM: empieza siempre aquí.

🔵 Q5_K_M — Alta Calidad

5 bits · ~5.7 GB (8B). Mejor que Q4 en razonamiento complejo y código. Usa cuando tienes VRAM extra (12+ GB).

🔵 Q8_0 — Máxima Fidelidad

8 bits · ~9.2 GB (8B). Prácticamente igual al modelo original. Requiere 16+ GB VRAM para modelos 8B.

⚠️ Q2/Q3 — Solo casos extremos

2–3 bits · 2.5–3.3 GB. Degradación notable — el modelo puede producir respuestas incoherentes. Solo si la RAM es muy limitada.

🔬 F16 — Investigación / Fine-tuning

16 bits · ~16 GB (8B). Precisión completa. Solo para fine-tuning o benchmarks. Inviable en uso cotidiano.

Sección 03

Censurado vs. Uncensored

La diferencia no está en los datos base sino en el proceso de alineación posterior al preentrenamiento.

🔒
Modelo Censurado (RLHF/DPO)
Ej: Llama-4-8B-Instruct (Meta oficial)

• Rechaza solicitudes sensibles activamente
• Restricciones sobre armas, hacking, adultos
• Ideal para asistentes de trabajo / empresarial
• Puede ser "sobre-cauteloso" en ficción creativa
🔓
Modelo Uncensored (Abliterated)
Ej: Llama-3-8B-Lexi-Uncensored

• Responde sin filtros activos
• Ideal para escritura adulta, roleplay, investigación
• Libertad total de expresión y creación
• Requiere uso responsable del usuario
✅ ¿Funciona en LM Studio?

Sí. LM Studio no tiene mecanismo de verificación de contenido. Cualquier .gguf válido se carga y corre. Creadores confiables: Eric Hartford (Dolphin), Orenguteng (Lexi), bartowski (GGUF).

Busca en Hugging Face: uncensored gguf, dolphin gguf, abliterated gguf

⚖️ Legalidad

La legalidad depende del uso, no del modelo. Descargarlo es legal en la mayoría de jurisdicciones. Lo ilegal es el output dañino que generes, no el modelo en sí.

⛔ Advertencia

Nunca uses modelos uncensored para generar contenido ilegal. El output es tu responsabilidad legal exclusiva.

    Sección 07

    Servidor Local (API)

    Expone una API HTTP compatible con OpenAI en el puerto 1234. Cambia la URL base — sin cambiar el código de tus apps.

    Checklist — activar el servidor

      BROWSERhttp://localhost:1234/v1/models
# Si ves JSON = servidor activo ✅
      PowerShell$body = '{"model":"local","messages":[{"role":"user","content":"Hola"}]}'
curl -X POST http://localhost:1234/v1/chat/completions `
  -H "Content-Type: application/json" `
  -d $body
      Pythonfrom openai import OpenAI
client = OpenAI(
  base_url="http://localhost:1234/v1",
  api_key="lm-studio"
)
resp = client.chat.completions.create(
  model="local",
  messages=[{"role":"user","content":"Hola"}],
  temperature=0.7, max_tokens=500
)
print(resp.choices[0].message.content)
      ✅ Compatible con LangChain, AutoGen, CrewAI, n8n, Open WebUI

      Cambia base_url a http://localhost:1234/v1 en cualquier framework.
